## 📄 Описание (v1.0.0)

Дорогие друзья (если таковые имеются), на этот раз я решил представить вам ещё один свой проект: простой калькулятор написанный на языке программирования Python **(Simple Python Calculator)**, т.к я программирую именно на нём. **Simple Python Calculator** использует следующие библиотеки:

- **PyQt5** - интерфейс и графика
- **Screeninfo** - получение размеров экрана

Я хотел сделать простое приложение, которое может стать примером того как можно быстро и легко написать небольшую программу с использованием данной графической библиотеки (как современная альтернатива Tkinter).

Проект распространяется под лицензией **GPLv3** (GNU General Public License) из-за использования PyQt5 (Open Source) и юридических аспектов Riverbank Computing Limited.

**Готовое .exe приложение находится в разделе Releases**

## 📄 Description (v1.0.0)

Dear friends (if you have any), this time I'd like to introduce you to another project: a simple calculator written in Python **(Simple Python Calculator)**, as that's what I program in. **Simple Python Calculator** uses the following libraries:

- **PyQt5** - interface and graphics
- **Screeninfo** - screen dimensions

I wanted to create a simple application that could serve as an example of how quickly and easily you can write a small program using this graphics library (as a modern alternative to Tkinter).

The project is licensed under the **GPLv3** (GNU General Public License) due to the use of PyQt5 (Open Source) and the legal aspects of Riverbank Computing Limited.
